# Contributing

Thank you for considering contributing to the Laravel Signhost package!  
General contribution guidelines can be found in the [Laravel documentation](https://laravel.com/docs/contributions).

## Bug Reports

Bug reports should be submitted via GitHub Issues.  
To encourage active collaboration, we prefer pull requests over standalone bug reports. If possible, please include a failing test case demonstrating the issue.

## Pull Requests

1. Fork the repository and create your branch.
2. Make your changes.
3. Write tests for your changes.
4. Ensure all tests pass.
5. Submit a pull request.

Please keep pull requests focused and reference any related issues where applicable.

## Coding Style

This package follows the [PSR-12](https://www.php-fig.org/psr/psr-12/) coding standard and the [Laravel coding style](https://laravel.com/docs/contributions#coding-style).  
Use the Laravel Pint plugin for your favorite IDE to ensure a consistent coding style.

## Testing

We use PestPHP for testing.  
Run `vendor/bin/pest` to execute the test suite. All new features and bug fixes must be covered by tests.
